# Olympics Streamlit Web App

This directory contains the interactive web application for exploring the Olympics dataset. The app presents analytical tables and visualizations for medals, athletes, countries, sports, and participation trends.

## Running locally

1. Create or activate a Python environment.
2. Install the dependencies listed by the project setup files.
3. Start the Streamlit entry point used by the app:

   ```bash
   streamlit run app.py
   ```

The application expects the Olympics data files and helper modules to remain available at the paths used by the source code. The `.venv` and IDE metadata directories are local development artifacts and are not required for deployment.
